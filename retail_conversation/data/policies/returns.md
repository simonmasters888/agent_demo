# Returns Policy

Customers can return eligible items within 30 days of delivery.

Items must be unworn, unused, and in resaleable condition.

A receipt or order record is required.

Items already marked as returned cannot be returned again.

Final-sale items are not eligible for return.

If an order is outside the 30 day return window, the customer should be offered escalation only when there is a delivery issue, product fault, or other exceptional circumstance.
